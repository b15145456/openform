# 文件慣例（所有 repo 共用）

> 此文件沿用 BotHangar 的共用文件規範。每個 repo 使用相同心智模型。

## 骨幹檔
`README.md`：專案入口。`CLAUDE.md`：AI 工作上下文。`docs/README.md`：唯一文件索引。`docs/HANDOFF.md`：逐 session 紀錄。`docs/PROGRESS.md`：里程碑。`docs/TODO.md`：待辦。

## 四類文件
1. 上手 / 教學：安裝、使用、tutorial。
2. 參考：架構、spec、runbook。
3. 決策 / 設計：ADR、設計取捨。
4. 紀錄：HANDOFF、PROGRESS、TODO。

## Session
進 session 先讀 HANDOFF 最新一筆與 TODO。實質修改後：HANDOFF 最上方新增 YYYY-MM-DD；更新 TODO；重大進展更新 PROGRESS。日期使用 YYYY-MM-DD。
